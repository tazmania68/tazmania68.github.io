Características

Todo lo que necesitas para dominar la guerra de clanes

Desde detección de ataques en tiempo real hasta predicciones de ranking — el tracker lo tiene todo.

Tracking en vivo

Lectura del ranking cada segundo (modo turbo 0.5s). Detecta ganancias y pérdidas de reputación al instante con Server-Sent Events.

Detección de ataques

Empareja automáticamente quién atacó a quién: si un clan gana X y otro pierde X, el ataque queda registrado con atacante y víctima.

Bleed / Sangrado

Detecta cuando un clan pierde reputación de forma continua. Recibe alertas instantáneas cuando tu clan está siendo quemado.

Miembros y Top Burn

Lee los miembros de cada clan en paralelo y descubre qué jugador específico está atacando. Top Burn por clan en tiempo real.

Alertas Discord + Telegram

Webhook de Discord con embeds ricos y bot de Telegram interactivo. Comandos: /status, /top, /bleed, /predict, /card y más.

Predicciones de ranking

Calcula el ritmo de cada clan (REP/min) y proyecta el ranking final de temporada. ¿Quién será el #1? El tracker te lo dice.

Gráficas de historial

Reputación de cada clan a lo largo del tiempo: 26 horas en alta resolución y 41 días de histórico comprimido.

Puntaje de amenaza

Evalúa qué clanes son más peligrosos según su actividad, rachas de ataque y ritmo de crecimiento. Prepárate antes de que ataquen.

Cómo funciona

Tres pasos y estás dentro

Sin cuentas, sin registros, sin configuración complicada.

1. Descarga

Un solo archivo zenshin_tracker.py. No necesita instalación de librerías — funciona solo con Python 3.8+.

2. Ejecuta

Abre una terminal y escribe python3 zenshin_tracker.py. El tracker empieza a leer el ranking automáticamente.

3. Observa en vivo

Abre http://localhost:8000 en tu navegador. Verás el ranking, ataques, bleed y predicciones actualizándose en tiempo real.

Instalación rápida

Listo en menos de un minuto

Copia y pega estos comandos en tu terminal.

# Clonar el repositorio
git clone https://github.com/TU_USUARIO/zenshin-tracker.git
cd zenshin-tracker

# (Opcional) Instalar Pillow para generar imágenes
pip install -r requirements.txt

# Ejecutar el tracker
python3 zenshin_tracker.py

# Tracker v23 listo -> abre http://localhost:8000
